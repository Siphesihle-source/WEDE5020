# Simza's Car Wash Website

## WEDE5020 – Web Development

### Project Overview

This project involves the design and development of a website for **Simza's Car Wash**, a car-washing business established in 2022. The purpose of the website is to provide customers with information about the business, its services, contact details and enquiry options.

The website was developed in three parts, with each part introducing improvements and additional functionality.

## Part 1: HTML Website Development

Part 1 focused on creating the basic structure of the website using HTML.

The following pages were developed:

- Home page
- About Us page
- Services page
- Contact page
- Enquiry page

HTML elements were used to organise the website content, navigation, headings, paragraphs, images and links.

## Part 2: CSS Styling and Website Design

Part 2 focused on improving the appearance and layout of the website using CSS.

The improvements included:

- Applying consistent colours and styling across the website.
- Improving navigation and page layouts.
- Styling headings, paragraphs, images and service sections.
- Improving the appearance of forms and contact information.
- Adding responsive styling to improve usability on different screen sizes.
- Maintaining a consistent business identity throughout the website.

## Part 3: JavaScript Functionality and Final Improvements

Part 3 focused on introducing JavaScript functionality and improving the overall website experience.

The additional features included:

- Service searching and filtering.
- Form validation to check customer input.
- Interactive FAQ functionality.
- Image lightbox functionality.
- Additional CSS improvements.
- Search Engine Optimisation (SEO) elements, including page titles and meta descriptions.
- Preparing the website for online deployment using GitHub Pages.

## Technologies Used

- **HTML5:** Website structure and content.
- **CSS3:** Website styling, layouts and responsiveness.
- **JavaScript:** Interactive website functionality.
- **Font Awesome:** Icons used throughout the website.
- **Google Fonts:** Typography.
- **GitHub:** Version control and project hosting.
- **GitHub Pages:** Website deployment.

## How to Run the Project Locally

1. Download or clone the repository.
2. Extract the downloaded files if necessary.
3. Open the project folder in Visual Studio Code.
4. Open the `WEBSITE_PART_1` folder.
5. Open `Index.html` in a browser or use the Live Server extension in Visual Studio Code.

## Project Structure

The project contains HTML pages, CSS stylesheets, JavaScript files and image assets organised into folders.

- `WEBSITE_PART_1/` – Contains the website HTML pages and images.
- `css/` – Contains the additional Part 3 stylesheet.
- `js/` – Contains the Part 3 JavaScript functionality.
- `style.css` – Contains the main website styling.
- `README.md` – Contains the project documentation.

## Conclusion

The development of Simza's Car Wash website progressed from a basic HTML website in Part 1 to a styled and responsive website in Part 2, followed by the addition of interactive JavaScript features in Part 3. The final website provides customers with an accessible platform to learn about the business, explore its services and make enquiries.
